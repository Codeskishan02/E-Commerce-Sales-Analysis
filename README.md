# E-Commerce-Sales-Analysis
Project Overview
This project analyzes e-commerce sales and order data using SQL.

Tools Used
MySQL
SQL
VS Code
Apple Numbers
Dataset
The dataset contains 120 e-commerce orders with information about customers, products, cities, quantities, prices, discounts, payment methods, order status, and sales amount.

## Project Results

The following key performance indicators (KPIs) were calculated using SQL:

- Total Sales: ₹2,87,789.30
- Total Orders: 120
- Total Quantity Sold: 253
- Average Order Value (AOV): ₹2,398.24

### Category-wise Sales Analysis

Sales were grouped by product category and sorted from highest to lowest to identify the categories contributing the most revenue.
