How to Present This Dashboard

A simple 2–3 minute walkthrough for a college presentation or interview

  1. Introduction: “My project is E-Commerce Sales & Order Analysis. I analyzed 120 e-commerce orders from 2025.”
  2. Tools: “I cleaned the dataset, used MySQL to write SQL queries, and built this interactive dashboard to visualize results.”
  3. KPIs: “The full dataset has ₹2,87,789.30 in recorded sales, 120 orders, 253 units and an average order value of ₹2,398.24.”
  4. Charts: “This line chart shows monthly sales. These bar charts compare product categories, products and cities.”
  5. Live demo: Select a category or city above and explain how all KPIs and charts update together.
  6. Conclusion: “This project improved my data cleaning, SQL, KPI analysis and dashboard skills.”
