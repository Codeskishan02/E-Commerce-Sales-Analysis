# E-Commerce Sales & Order Analysis

## Project Overview

This project analyzes e-commerce sales and order data using SQL.

## Tools Used

- MySQL
- SQL
- VS Code
- Apple Numbers

## Dataset

The dataset contains 120 e-commerce orders with information about customers, products, cities, quantities, prices, discounts, payment methods, order status, and sales amount.

## Analysis Performed

- Total sales
- Total orders
- Total quantity sold
- Average order value
- Category-wise sales
- City-wise sales
- Payment method analysis
- Order status analysis
- Top products
- Top customers
- Monthly sales
- Discount analysis
